# 🔐 Login Form

A simple and responsive Login Form created using HTML and CSS. This project features a modern user interface with a gradient background, email and password input fields, a login button, and a sign-up link.

## 📌 Features

- Modern Login Form UI
- Gradient Background
- Email and Password Input Fields
- Login Button
- Forgot Password Text
- Sign Up Link
- Clean and Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```
Login-Form/
│── index.html
│── signup.html
│── README.md
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.

## 📚 Concepts Used

- HTML Forms
- Input Fields
- CSS Flexbox
- Linear Gradient Background
- Border Radius
- Links (`<a>`)
- Basic Responsive Layout

## 📸 Output

The webpage displays:
- Login Form heading
- Email or Phone input field
- Password input field
- Forgot Password option
- Login button
- Sign Up link for new users
